# NeoCRM 跨平台开发者桌面客户端 (NeoCRM Desktop Studio)

专为销售易 (NeoCRM) PaaS 开发者打造的现代化桌面管理工作台，完整支持 **macOS** 与 **Windows**。具备 OAuth2 统一登录与多环境管理能力，深度集成**元数据管理（对象/字段创建、Excel 批量导入、对象字典同步）**与**专业级数据中心（精准查询与穿透、关联查找 Lookup、批量导出）**。

---

## 核心三大功能模块

### 1. 🏠 控制台与环境管理 (Dashboard & Session)
* **多环境管理**：线上生产、沙盒演练、开发测试 (CD)、P20、腾讯云 UAT 以及任意自定义环境，支持实时网络延迟测速。
* **3 种灵活登录**：内嵌专属授权窗口（免跳出应用）、外部浏览器标准授权、账号密码直登。
* **Token 生命周期看板**：租户信息、用户信息、Access Token 剩余有效期动态倒计时、手动续期。
* **快捷工具中心**：Web/H5 UI 设计器直达、即时测试 API 通信状态。
* **多账号无感切换**：历史多租户/账号自动存档，一键切换。

### 2. 📦 对象与字段元数据中心 (Metadata Studio)
* **对象字典全量同步**：一键调用接口拉取租户下所有**标准实体**与**自定义实体**，直观展现名称、API Key、类型、是否支持明细/业务类型/触发器等。
* **一键导出字典文档**：将全量对象结构导出为 `AllxObjects.md` 规范文档至本地工程。
* **创建自定义业务实体 (Object)**：
  * 支持自定义 API Key（系统自动追加 `__c` 后缀）、显示名称、业务描述。
  * 主字段支持**普通文本**或**自动编号 (AutoNumber)**（如 `AC{YYYY}{MM}{DD}{000}`）。
  * 支持一键开启服务端脚本触发器 (Trigger) 与多业务类型支持。
* **实体字段浏览与单条新增 (Field)**：
  * 支持创建文本、多行文本、单选列表、多选列表、整数、金额、日期、电话、邮箱、布尔值等 14+ 种类型。
* **Excel 批量创建字段 (Batch Field Creation)**：
  * **一键下载标准 Excel 模板**：预置典型字段类型示例与格式注解。
  * **智能表头与类型映射**：自动识别 Excel 中的中英文表头，中文类型自动转为平台系统代码。
  * **下拉选项自动提取**：支持 `选项A:1, 选项B:2` 或 `启用, 停用` 等多格式解析。
  * **导入前可视化预检**：标示“待创建”、“已存在”、“格式错误”，支持在表格中直接二次编辑调整与勾选。
  * **动态进度看板与限流保护**：实时环形进度条、日志流水，智能防并发限流。
  * **失败一键重试**：任务执行报告统计，支持对失败字段定向重试。

### 3. 📊 数据中心全功能工作台 (Data Studio)
按业务场景清晰划分为三大独立子模块：

#### ① 数据精准查询与关联穿透 (Data Viewer)
* **多模态智能查询**：
  * 支持直接输入**数据 ID**（如 `4172298234169380`）；
  * 支持直接**粘贴销售易 CRM 页面 URL 链接**，系统智能自动解析提取实体类型与数据 ID；
  * 支持输入**数据 Name**（如客户名称）进行模糊匹配检索。
* **字段全景呈现**：结构化展示记录的所有字段名称（中文）、API Key、类型与数值。
* **关联关系与主子明细智能联动**：
  * 遇到关联外键字段时，**不只展示数字 ID，自动解析呈现对应关联对象的真实 Name**（例如 `所属客户: 联想集团有限公司 (ID: 4172298234169380)`）。
  * **支持点击钻取**：点击关联对象，以侧边抽屉形式**穿透展开该对象的完整数据内容**，支持无限层级继续穿透！

#### ② 数据插入 / 更新 (Data Editor & Lookup)
* **模式切换**：支持“新建数据记录 (Insert)”与“更新已有数据 (Update)”。
* **关联数据查找组件 (Record Lookup)**：
  * 针对关联字段或主子明细，杜绝手动盲输 ID！
  * 点击 **“🔍 查找”** 按钮呼出关联数据查询弹窗，支持按 Name 或 ID 实时检索并勾选回填，自动带出可读名称与 ID。
* **表单与 JSON 双模编辑**：既支持字段可视化表单录入，也支持随时切换为 JSON 高级代码视图。

#### ③ 批量数据导出中心 (Data Exporter)
* **自由定制导出**：选择对象、勾选要导出的字段列范围（支持全选/反选）。
* **自定义过滤**：支持设置 WHERE 条件表达式与最大导出条数。
* **多格式输出**：一键生成 **Excel (.xlsx)**、**CSV (.csv)** 或 **JSON (.json)** 格式下载。

## 快速运行与构建

### 1. 本地启动开发模式
```bash
npm run dev
```

### 2. 跨平台打包发布
* **macOS 安装包 (.dmg)**：
  ```bash
  npm run dist:mac
  ```
* **Windows 安装包 (.exe)**：
  ```bash
  npm run dist:win
  ```
