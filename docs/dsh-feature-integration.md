# DSH 能力参考与桌面端适配

桌面端不运行 DSH 的 Cordis 插件；以下功能由现有 Electron 模型循环实现，参考各项目的功能和安全边界，并非完整移植。

- [dsh-free-search](https://github.com/DDDMUC/dsh-free-search)（MIT）：无需密钥的 DuckDuckGo 和 Bing 搜索，搜索失败或无结果时尝试下一个来源，最终失败时明确返回提示；不生成模拟搜索结果。第三方服务可能限流或改变页面结构。
- [dsh-auto-continue](https://github.com/HsiangNianian/dsh-auto-continue)（MIT）：在设置中选择启用，模型明确报告输出长度限制或流式网络中断时最多续跑两次。已接收到工具调用的中断不自动重试，停止操作优先。现有 HTTP 连接重试与上下文压缩独立运作；没有移植重启恢复、自主循环和插件统计界面。
- [dsh-cost-meter](https://github.com/Han-1413141/dsh-cost-meter)（MIT）：优先统计模型接口实际返回的 token 用量；接口不返回时按请求和回复内容本地估算并标明，历史消息未记录时不追溯；按明确的模型名称自动匹配内置美元或人民币公开 API 参考单价，网关同样适用；金额并非网关实际账单，也可在模型容量设置中手动覆盖，消息和会话显示估算费用。未配置模型价格时不计算金额；缓存、套餐、峰谷、思考 token、图像及其他计费因素可能导致估算与账单不同。内置价格按标注日期核验且不是在线价格同步，部分定价到期自动停用；未接入供应商余额或套餐额度。
- [dsh-mask](https://github.com/PerryLink/dsh-mask)（Apache-2.0）：可选对话文本遮罩，以本轮内存映射替换常见 API 密钥、邮箱、中国大陆手机号、身份证和通过 Luhn 校验的部分银行卡；完成回复后仅在本机还原。开启时禁用工具、图片和对话压缩，避免占位符进入业务写操作或图片内容绕过文本遮罩。姓名、地址、未通过校验的卡号及其他秘密不保证识别，原始会话仍存本机，本功能不能作为全面数据防泄漏保证。
