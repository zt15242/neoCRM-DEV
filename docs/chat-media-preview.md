# 对话中的图片与图表

回复正文支持以下展示方式：

- 图片：`![说明](https://example.com/image.png)`；图片扩展名的普通链接和 HTTP/HTTPS 直链也会显示图片。支持当前项目和已上传附件中的本地图片，文件名可含空格或括号。
- 流程图、时序图、ER 图、思维导图：使用 `mermaid` 代码块；`mmd` 和 `mindmap` 代码块也可识别。项目里的 `.mmd`、`.mermaid` 文件可通过 Markdown 链接预览。
- XMind：上传 `.xmind` 文件，或使用 `[方案](<项目中的方案.xmind>)` 引用。兼容包含 `content.json` 的新格式和包含 `content.xml` 的旧格式，支持多画布切换及主题层级展开。`read_document` 可按画布读取主题文本。

预览支持缩放和放大查看，图表可查看、复制源码。流式生成中的未闭合图表等待代码块完成；已完成的代码块可立即显示。图表语法错误时保留源码入口；图片加载失败或超时后可重试及打开原链接。

XMind 展示主题层级，原有样式、附件、备注和跨主题关联线需在 XMind 中查看。远程 XMind 链接保留为下载链接，下载后添加为对话附件即可预览。需要登录或不允许外部访问的图片可能仍需打开原链接查看。

本地预览只读取当前已登记项目或当前对话明确添加的单个附件，校验规范路径和符号链接。图片与 XMind 文件最大 20 MB，XMind 主题内容最大 4 MB、1500 个主题、32 层；Mermaid 最大 40000 字符、600 条边。图表不执行 HTML、脚本或配置指令，不加载外部资源。

验证：`node scripts/test-message-media.mjs` 覆盖新旧 XMind、实际 Electron 渲染、流式输出、失败回退、交互及文件边界。设置 `NEO_MEDIA_PREVIEW_DIR` 可保存测试截图和自包含浏览器样例。
